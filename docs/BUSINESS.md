# เล่าไว้ — เอกสารธุรกิจ (ร่าง v1)

> **ร่างจากการบ้านที่ mentor ฝากไว้รอบ 1** — ทีมต้องเอาไปแทนด้วยตัวเลขจริงและข้อมูลสัมภาษณ์จริง
> ทุกจุดที่เขียน `[ต้องยืนยัน]` คือยังเป็นสมมติฐาน **ห้ามเอาขึ้นเวทีทั้งที่ยังเดา**
> ถ้ากรรมการถามแล้วเราตอบว่า "ยังไม่ได้ทดสอบ" จะได้คะแนนมากกว่าตอบตัวเลขที่แต่งขึ้น

## 1. Persona

mentor: *"พอเรามีหน้าลูกค้าชัด เลยทำให้เรารู้ว่าลูกค้าต้องการอะไร"*

### 👩 คนจ่าย — "พี่แนน" อายุ 34
ลูกสาวคนโต ทำงานบริษัทในกรุงเทพ พ่อแม่อยู่โคราช

| | |
|---|---|
| กลับบ้าน | ปีละ 3 ครั้ง — สงกรานต์ ปีใหม่ และตอนมีงานบุญ |
| ช่องทางที่คุยกับแม่ | โทรวันละ 5 นาที ถามว่ากินข้าวหรือยัง |
| รายได้ | 35,000–60,000 บาท/เดือน |
| ของขวัญที่เคยซื้อให้พ่อแม่ | เครื่องนวด ทัวร์ไหว้พระ ของกิน — ของที่ "ซื้อง่ายแต่ไม่ได้แปลว่าใส่ใจ" |

**ความรู้สึกจริงที่อยู่ใต้ปัญหา** (ส่วนที่ mentor บอกว่าเรายังลงไม่ลึกพอ)
- **รู้สึกผิดที่ไม่มีเวลา** — กลับบ้านทีไรก็หมดไปกับงานบ้านและกับข้าว ไม่เคยได้นั่งฟังแม่เล่าจริงจัง
- **กลัวไม่ทัน** — เห็นแม่เดินช้าลง เริ่มลืมบางเรื่อง แต่ไม่กล้าคิดต่อ
- **ไม่รู้จะเริ่มถามยังไง** — ถามว่า "แม่สบายดีไหม" ทุกครั้ง แล้วก็จบแค่นั้น เพราะคำถามที่ลึกกว่านั้นรู้สึกเคอะเขิน
- **เคยลองอัดคลิปไว้** แล้วไม่เคยกลับมาเปิดฟัง เพราะยาวและหาไม่เจอ

**สิ่งที่เธอต้องการจริง ๆ ไม่ใช่ "หนังสือ"** แต่คือ *ข้ออ้างที่ทำให้ได้นั่งคุยกับแม่นาน ๆ โดยไม่เคอะเขิน* — หนังสือคือผลพลอยได้ที่พิสูจน์ว่าการคุยครั้งนั้นมีค่า

### 👵 คนเล่า — "ยายสมจิต" อายุ 78
อยู่บ้านกับลูกชายและหลานเล็ก

| | |
|---|---|
| เทคโนโลยี | ใช้ LINE ได้ ส่งสติกเกอร์เป็น พิมพ์ไม่ถนัด วิดีโอคอลได้ถ้าหลานโทรมา |
| จุดแข็ง | เล่าเก่งมาก จำรายละเอียดเก่า ๆ ได้ดีกว่าเรื่องเมื่อวาน |
| สิ่งที่กลัว | เป็นภาระ · ถูกมองว่าพูดมาก · ตายแล้วไม่มีใครจำได้ |
| สิ่งที่อยากได้ | มีคนตั้งใจฟัง และรู้สึกว่าเรื่องของตัวเองมีค่า |

> ข้อสังเกตเรื่องราคา: คนจ่ายกับคนใช้คนละคน — ยายไม่ได้จ่าย แต่ยายคือคนตัดสินว่าจะเล่าต่อไหม
> ถ้ายายไม่สนุก เรื่องจบตั้งแต่คำถามที่สอง **ประสบการณ์ของยายจึงสำคัญกว่า UI ของหลาน**

### ต้องไปเก็บเพิ่ม `[ต้องยืนยัน]`
สัมภาษณ์ครอบครัวจริง 5–10 ครอบครัว เพื่อตอบ 3 ข้อนี้
1. ปีหนึ่งได้กลับไปเจอกี่ครั้งจริง ๆ
2. เคยพยายามเก็บเรื่องของท่านไหม ล้มเหลวเพราะอะไร
3. ถ้ามีหนังสือเล่มนี้ ยินดีจ่ายเท่าไหร่ และจ่ายตอนไหน

> ระบบเก็บข้อ 1 ให้อัตโนมัติแล้วที่หน้า `/interview/new` — จบงานจะมีตัวเลขจริงพูดได้ทันที

## 2. คู่แข่ง

mentor: *"เจ้านั้นมีปัญหาอะไรที่เขาไม่ได้แก้ แต่เราเป็นคนแก้สิ่งนั้น"*

| คู่แข่ง | เขาทำอะไร | **ช่องว่างที่เขาไม่ได้แก้** |
|---|---|---|
| **Storyworth** (สหรัฐฯ พิมพ์แล้วกว่า 1 ล้านเล่ม) | ส่งคำถามทางอีเมลรายสัปดาห์ ให้ผู้สูงอายุ **เขียนตอบเอง** แล้วรวมเป็นเล่ม | ผู้สูงอายุไทยไม่ถนัดพิมพ์ · เป็นภาษาอังกฤษ · **ไม่มีเสียง** · ภาระตกที่คนเล่าแทนที่จะเป็นคนฟัง |
| **HereAfter AI** | สัมภาษณ์ด้วยเสียง แล้วสร้างบอทให้ครอบครัวถามตอบได้หลังท่านจากไป | ไปทาง deadbot ซึ่งงานวิจัยเคมบริดจ์ 2024 เตือนเรื่องผลต่อจิตใจ · ไม่มีหนังสือที่ถือได้ · ไม่รองรับไทย |
| **StoryFile** | วิดีโอสัมภาษณ์แบบโต้ตอบได้ | ต้นทุนสูง ต้องถ่ายวิดีโอ · ไม่เหมาะกับบ้านทั่วไป · ไม่รองรับไทย |
| **ร้านทำหนังสืองานศพ** | รวบรวมประวัติแล้วจัดพิมพ์ | ทำ **หลัง** ท่านจากไปแล้ว ญาติต้องเดาเรื่องเอง · ไม่มีเสียงของท่าน · เร่งรีบภายในไม่กี่วัน |
| **ChatGPT + อัดเองในมือถือ** | ฟรี ทำเองได้ | ไม่มีชุดคำถามช่วยสัมภาษณ์ · **AI แต่งเติมได้โดยไม่มีใครรู้** · ตรวจที่มาไม่ได้ · ไม่มีเล่ม ไม่มี QR |

### ทำไมเราถึงจะ "อยู่ได้นานที่สุด"
mentor บอกว่าผู้ชนะไม่ใช่คนแรก แต่คือคนที่อยู่ได้นานที่สุด คำตอบของเราคือ **Dialect Correction Flywheel**

```
ครอบครัวใช้งาน → AI ถอดคำถิ่นผิด → ครอบครัวแก้ให้ (เขาอยากได้หนังสือที่ถูกอยู่แล้ว)
      ↑                                            ↓
ถอดเสียงแม่นขึ้น ← dataset คู่คำไทย-ถิ่นโตขึ้น ←────┘
```

- คู่แข่งต่างชาติไม่มีทางได้ข้อมูลนี้ เพราะไม่มีผู้ใช้ไทย
- คู่แข่งไทยที่เข้ามาทีหลังต้องเริ่มจากศูนย์ ขณะที่เรามีสะสมไว้แล้ว
- **ไม่ต้องขอเสียงใครไปเทรน** — เราเก็บแค่คู่ข้อความ (ผิด → ถูก) + ภาค ไม่เก็บเสียง ไม่เก็บชื่อ
  จะผูกกลับไปที่เสียงได้ต่อเมื่อครอบครัวติ๊กยินยอมแยกต่างหาก

ตัวเลขนี้นับอยู่จริงในระบบแล้ว แสดงที่หน้าตรวจว่า *"คู่คำภาษาถิ่นที่เก็บได้ N"*

## 3. จะหาลูกค้ายังไง (GTM)

mentor: *"จะหาลูกค้ายังไง แล้วทุกคนจะมาเจอโปรดักส์ของเรายังไง"*

เรียงจากต้นทุนต่ำไปสูง และจากที่ทำได้ทันทีไปที่ต้องใช้เวลา

| # | ช่องทาง | ทำไมถึงเวิร์ก | ทำได้เมื่อไหร่ |
|---|---|---|---|
| 1 | **คอนเทนต์เสียงจริง** ลง TikTok/Reels — คลิปสั้นเสียงคุณยายเล่าเรื่อง + ข้อความบนจอ | ตัวสินค้าคือคอนเทนต์ในตัวเอง ต้นทุนเท่ากับเวลาตัดต่อ และเป็นของที่คนแชร์ให้พี่น้องดู | ทันที |
| 2 | **ฤดูกาลของขวัญ** วันแม่ · วันพ่อ · สงกรานต์ · ปีใหม่ | คนหาของขวัญให้พ่อแม่อยู่แล้วและหาไม่เจอทุกปี เป็นจังหวะที่ความรู้สึกผิดสูงที่สุด | ทันที |
| 3 | **ธุรกิจจัดงานศพ** เสนอเป็นบริการเสริม "ทำไว้ล่วงหน้า" | เขามีลูกค้าที่กำลังคิดเรื่องนี้พอดี และได้ของที่ขายเพิ่มโดยไม่ต้องลงทุน | หลัง pilot |
| 4 | **ศูนย์ดูแลผู้สูงอายุ / อบต.** จัดเป็นกิจกรรม "วันเล่าเรื่อง" | มีผู้สูงอายุรวมกันอยู่แล้ว มีงบกิจกรรม และได้ทดสอบภาษาถิ่นหลายภาคพร้อมกัน | หลัง pilot |

**ช่องทางที่ 1 คือจุดเริ่มที่สำคัญที่สุด** เพราะเสียงจริงของผู้สูงอายุคือคอนเทนต์ที่คนหยุดดู
และมันพิสูจน์สินค้าไปพร้อมกับการตลาด — ไม่ต้องแยกงบ

## 4. รายได้ 4 ทาง

mentor บอกว่า 2 ทางยังเสี่ยง ควรมี 3–4

| # | ทาง | ใครจ่าย | จังหวะที่จ่าย | ราคา |
|---|---|---|---|---|
| 1 | **หนังสือต่อเล่ม** | ลูกหลานวัยทำงาน | ตอนทำเสร็จ | `[ต้องยืนยัน]` รอราคาโรงพิมพ์จริง |
| 2 | **สมาชิกคลังความทรงจำรายปี** | ครอบครัว | ต่อเนื่อง | `[ต้องยืนยัน]` |
| 3 | **หนังสืออนุสรณ์ผ่านพาร์ทเนอร์งานศพ** | ครอบครัวผู้เสียชีวิต (ผ่านร้าน) | ตอนจัดงาน | แบ่งรายได้กับร้าน `[ต้องยืนยัน]` |
| 4 | **บริการช่วยทำแบบมีคนดูแล** (ใหม่) | ครอบครัวที่ไม่ถนัดทำเอง หรือท่านป่วย/พูดไม่ชัด | ครั้งเดียวต่อเล่ม | สูงกว่าแบบทำเอง `[ต้องยืนยัน]` |

**ทางที่ 4 เพิ่มเข้ามาเพราะ** persona ของเราคือคนที่ *ไม่มีเวลา* — บางครอบครัวพร้อมจ่ายเพื่อให้มีคนมาช่วยสัมภาษณ์แทน
และมันใช้โครงสร้างเดียวกันทั้งหมด ต่างแค่มีคนของเราช่วยถาม ไม่ต้องสร้างระบบใหม่เลย

### ใช้ฟรีได้แค่ไหน
ดิจิทัลใช้ฟรี — อ่านบนเว็บและฟังเสียงได้ไม่จำกัด เก็บเงินเมื่อ **ต้องการของที่จับต้องได้** หรือ **ต้องการให้เราช่วยทำ**
เหตุผล: ของฟรีทำให้ครอบครัวกล้าเริ่ม และการเริ่มคือสิ่งที่ยากที่สุดในปัญหานี้

### ตัวเลขที่ต้องเติมก่อน pitch `[ต้องยืนยัน]`
- ต้นทุนพิมพ์จริง A5 ปกแข็ง 60–80 หน้า ที่ 1 / 10 / 50 เล่ม — **ศิลปโทรโรงพิมพ์ 3 เจ้า**
- ต้นทุน API ต่อเล่ม (เสียงประมาณ 60 นาที = กี่บาท)
- ราคาที่ครอบครัวบอกว่ายอมจ่าย จากการสัมภาษณ์จริง
- Gross margin ต่อเล่ม

## 5. สิ่งที่เราตั้งใจไม่ทำ

- **ไม่ pivot ไปกลุ่มศิลปิน/ไอดอล** แม้ mentor จะเปิดประเด็นไว้ เพราะท้ายสุดเขาสรุปเองว่าให้เลือก target เดียว
  *ถ้ากรรมการถาม:* "โครงสร้างเดียวกันขายกลุ่มศิลปินได้ และเราเห็นโอกาสนั้น
  แต่เลือกโฟกัสหลาน-ปู่ย่าตายายก่อน เพราะเป็นกลุ่มที่เรามีประสบการณ์ตรงและทดสอบได้จริงใน 2 วัน"
- **ไม่เคลมว่ารองรับทุกภาษาถิ่น** — อีสานมีผลทดสอบ (Typhoon ASR CER 8.85%) เหนือ/ใต้ยังไม่มี
  เราบอกตรง ๆ และออกแบบให้แก้ข้อความได้เสมอ
- **ไม่ทำ deadbot** ไม่โคลนเสียง ไม่สร้างบุคลิกจำลองของผู้เสียชีวิต
