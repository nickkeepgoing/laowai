### 3 ตาราง
```sql
sessions (id, elder_name, relation, topic, consent_audio_url, created_at)
clips    (id, session_id, question, audio_url, duration_ms,
          transcript, claims jsonb, next_questions jsonb, created_at)
chapters (id, session_id, title, paragraphs jsonb, approved bool,
          share_token text unique, created_at)
```
`claims` → `[{id:"c1", quote:"ถ้อยคำต้นฉบับเป๊ะ", summary, start_ms, end_ms, verified}]`
`paragraphs` → `[{text, claim_ids:["c1","c3"], flags:["ประโยค 2 เกินต้นฉบับ"]}]`

### หัวใจของทั้งโปรเจกต์ (15 บรรทัด)
```ts
const norm = (s: string) =>
  s.replace(/[\s​]/g, '').replace(/[.,!?"'()ฯๆๆ]/g, '');

export const verifyClaim = (transcript: string, quote: string) =>
  norm(transcript).includes(norm(quote));          // ไทยไม่มีช่องว่าง → ตรงไปตรงมา

export const verifyChapter = (paragraphs, byId) =>
  paragraphs.every(p => p.claim_ids.length > 0 &&
                        p.claim_ids.every(id => byId[id]?.verified));
```
Claim ที่ `verified:false` → **ทิ้ง** ไม่เอาไปเรียบเรียง และโชว์ให้ผู้ใช้เห็นว่าทิ้งกี่อัน (เป็นจุดขาย)

## 6. ข้อเดียวที่ผมยังยืนยัน: PDF ทำด้วย HTML print ไม่ใช่ react-pdf

**ไม่ใช่เรื่องเวลา แต่เป็นเรื่องคุณภาพ** — react-pdf ไม่ทำ complex text shaping ของไทย สระบน/ล่างกับวรรณยุกต์จะซ้อนผิดตำแหน่ง (เช่น "สื่อ" "ปู่" "ก๊อง") และตัดบรรทัดกลางคำ หนังสือจะออกมา**น่าเกลียด** ส่วน HTML print ใช้ text shaping ของเบราว์เซอร์ซึ่งทำไทยถูกต้อง 100%

เราจะได้ PDF **ทั้ง 2 ทาง**: Ctrl+P (ชัวร์ ใช้บนเวที) + ปุ่มดาวน์โหลดฝั่ง server ด้วย Puppeteer ซึ่งก็ render ด้วย Chrome ตัวเดียวกัน ได้ไฟล์สวยเหมือนกัน

## 9. คำถามกรรมการที่ต้องซ้อม
1. ต่างจาก ChatGPT ยังไง → ชุดคำถาม + ทุกย่อหน้าอ้างเสียงต้นฉบับ **ตรวจด้วยโค้ด ไม่ใช่ AI ตรวจ AI** + ครอบครัวบังคับตรวจ + ได้หนังสือฟังเสียงได้
2. ทำไมไม่โคลนเสียง → งานวิจัย Cambridge 2024 เรื่อง deadbot · เราเก็บเสียงจริง ไม่สร้างของปลอม
3. ภาษาถิ่นแม่นแค่ไหน → อีสานมีผล เหนือ/ใต้ **ยังไม่มีผล เราไม่เคลม** และแก้ข้อความได้เสมอ *(ตอบตรงได้คะแนนกว่าเคลมเกิน)*
4. ใครจ่าย เท่าไหร่ → ตัวเลขจริงจากศิลป
5. PDPA → consent ด้วยเสียง · สิทธิ์ลบ · ไม่เทรนโมเดล · token เพิกถอนได้
6. ผู้สูงอายุสมองเสื่อม → ผู้ดูแลยินยอมร่วม · หยุดได้ทุกเมื่อ · ไม่บันทึกช่วงที่ท่านสับสน · โหมดนี้ปิดการพิมพ์เผยแพร่
7. ถ้าท่านเล่าความลับครอบครัว → **ปุ่มลืม** กดโชว์ได้เลย
