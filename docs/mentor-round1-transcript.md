# บันทึกการคุย Mentor รอบ 1 — 18 พ.ย. 2569

> วัตถุดิบสำหรับสไลด์ **"ทำไมเราไม่เชื่อ AI ของเราเอง"**
> ถอดเสียงด้วย AI แล้วทีมมาตรวจเอง — ซึ่งกลายเป็นหลักฐานชั้นดีโดยไม่ได้ตั้งใจ

---

## 1. คำที่ AI ถอดผิด (ใช้บนสไลด์ได้เลย)

เงื่อนไขของเสียงชุดนี้: **คนหนุ่มพูดภาษากลางชัด ในห้องประชุมเงียบ**

| AI ถอดว่า | ที่จริงคือ | ทำไมถึงสำคัญ |
|---|---|---|
| "ภาษาอังกฤษ…แปลว่าเหนือกลางใต้" | **ภาษาถิ่น** | ผิดซ้ำ 5 ครั้งจนประโยคไม่มีความหมาย และผิดตรงคำที่เป็นหัวใจของบทสนทนาพอดี |
| "สมาชิกคลัง**เรือนจำ**รายปี" | คลัง**ความทรงจำ**รายปี | ชื่อสินค้าของเราเองยังผิด |
| "หนังสืออนุสรณ์ผ่านธุรกิจงาน**สุข**" | ธุรกิจงาน**ศพ** | ความหมายกลับด้านโดยสิ้นเชิง |
| "สตอรี่**เทรนนิ่ง**" | **storytelling** | คำทับศัพท์เพี้ยน |
| "มี**ถัง**เพิ่มไหม" | มี**คำถาม**เพิ่มไหม | ประโยคสั้น ๆ ก็ยังผิด |
| "pos**ential**" | potential | |
| "ซาวด์บาท" | **ซาวบาท** (20 บาท ภาษาเหนือ) | mentor ยกตัวอย่างคำถิ่นคำนี้เอง แล้ว AI ก็ถอดผิดจริง ๆ ในประโยคเดียวกัน |

### ประโยคที่ใช้บนเวที
> "นี่คือเสียงคนหนุ่มพูดภาษากลางชัด ๆ ในห้องเงียบ ยังผิดขนาดนี้
> แล้วเสียงคุณยายอายุ 80 พูดภาษาถิ่นจะผิดแค่ไหน
> เราจึงไม่ออกแบบระบบที่สมมติว่า AI ถูก เราออกแบบระบบที่สมมติว่า AI ผิดได้ทุกเมื่อ
> แล้วทำให้ครอบครัวจับผิดมันได้ง่ายที่สุด"

ต่อด้วย 3 กลไกที่มีอยู่จริงในโปรดักต์: อ้างถ้อยคำต้นฉบับ · กดฟังเทียบได้ · คนยืนยันก่อนพิมพ์

## 2. การบ้านที่ mentor ฝากไว้ (คำพูดจริง)

| # | ประเด็น | คำพูด |
|---|---|---|
| 1 | หน้าลูกค้าต้องชัด | "พยายามมองว่าตัวลูกค้าเป็นหลัก… ลูกค้าหน้าตาประมาณนี้ อายุประมาณเท่านี้ ความสัมพันธ์กับครอบครัวประมาณไหน มีเวลากลับบ้าน เยี่ยมบ้านบ่อยแค่ไหน… พอเรามีหน้าลูกค้าชัด เลยทำให้เรารู้ว่าลูกค้าต้องการอะไร" |
| 2 | ปัญหายังตื้น | "ปัญหาหนึ่งถึงสองข้อไม่พอ ปัญหามันสามารถลงไปชัดได้ ว่าความรู้สึกของลูกหลาน…" |
| 3 | คู่แข่ง | "ในตลาดตอนนี้มีใครที่ทำคล้าย ๆ กันมาก่อนไหม… เจ้านั้นมีปัญหาอะไรที่เขาไม่ได้แก้ แต่เราเป็นคนแก้สิ่งนั้น" / "ผู้ชนะของตลาดไม่ใช่คนที่เริ่มต้นคนแรก แต่คือคนที่อยู่ได้นานที่สุด" |
| 4 | ภาษาถิ่น | "ภาษาถิ่นมันไม่ได้มีแค่สี่ภาคหลัก มันมีภาษา local เข้าไปอีก… เสียงที่ออกมามันเพี้ยน ไม่ได้เป็นคำที่ตรง เรื่องนี้ก็ต้องมานั่งแก้ทีละอัน มนุษย์จะเป็นคนแก้" + แนะให้เก็บตัวอย่างคลื่นเสียงต่อคำถิ่น |
| 5 | ความเป็นไปได้จริง | "80% ยังไงก็พูดภาษากลางกันอยู่แล้ว… เขามองว่ามันเอาไปทำจริงได้มากน้อยแค่ไหน" |
| 6 | รายได้ + ช่องทาง | "ตอนนี้มีสองเรื่อง… พี่คิดว่ามันอาจจะมีสามหรือสี่ได้" / "จะหาลูกค้ายังไง แล้วทุกคนจะมาเจอโปรดักส์ของเรายังไง" |
| — | คำถามที่ทีมตอบไม่ได้ | "เปิดโทรศัพท์ทิ้งไว้เป็นชั่วโมงแบบนั้นมันจะกินแบตกับเน็ตไหม" → ทีมตอบ "ต้องถามทีมเดฟ" |
| — | กลุ่มลูกค้าใหม่ที่เสนอ | ศิลปิน/ไอดอลงบน้อยที่อยากทำชีวประวัติให้แฟนคลับ — แต่สรุปเองว่า "ตอนนี้เราอาจจะมองว่าหนึ่งทาร์เก็ตให้ชัดไปเลย" |
| — | รูปแบบ pitch | "พยายามใช้ storytelling เข้ามาจับ" |
| — | กติกา | ไม่มีรางวัลรองชนะเลิศ มีแค่ผู้ชนะ |

## 3. สิ่งที่เราทำไปแล้วจากการบ้านนี้

| การบ้าน | ทำอะไรไป |
|---|---|
| 1 หน้าลูกค้า | หน้า `/interview/new` ถามภาคและความถี่ที่ได้กลับไปเจอท่าน → เก็บลงฐานข้อมูลจริงตั้งแต่ผู้ใช้คนแรก |
| 3 + 4 คู่แข่ง/ภาษาถิ่น | **Dialect Correction Flywheel** — ฟอร์มแก้คำที่ถอดผิดในหน้าตรวจ ทุกการแก้เข้า dataset ภาษาถิ่น |
| 4 มนุษย์เป็นคนแก้ | หน้าตรวจบังคับให้ครอบครัวยืนยันก่อนสร้างหนังสือ + ไฮไลต์เหลืองชี้จุดที่ต้องดู |
| 5 ความเป็นไปได้ | ไม่เคลมว่ารองรับทุกภาษาถิ่น + ทำงานได้เมื่อเน็ตไม่ดี (คิวอัปโหลดใน IndexedDB) |
| คำถามแบต/เน็ต | opus 32 kbps → 3 นาที ≈ 0.7 MB โชว์ตัวเลขสดบนหน้าอัด ไม่เปิดไมค์ทิ้งไว้ ไม่สตรีมตอนอัด |
| กลุ่มศิลปิน | **ไม่ pivot** ตามที่ mentor สรุปเอง เก็บไว้ในสไลด์ roadmap |
| 2 ปัญหา / 6 รายได้+ช่องทาง | อยู่ใน `docs/BUSINESS.md` |
