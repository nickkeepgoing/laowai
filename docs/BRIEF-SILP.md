# บรีฟสำหรับศิลป — ก๊อปทั้งหน้านี้ไปวางใน Claude Code ของตัวเอง

## ขั้นตอนก่อนเริ่ม (10 นาที)
1. ลง Node.js LTS + Git
2. `git clone <repo ที่นิคส่งให้>` แล้ว `cd` เข้าไป
3. `npm install`
4. ขอไฟล์ `.env.local` จากนิคทางไลน์ แล้ววางไว้ที่ root
5. `npm run dev` → เปิด http://localhost:3000
6. เปิด Claude Code ในโฟลเดอร์นั้น แล้ววางข้อความด้านล่างทั้งก้อน

## 👇 ก๊อปตั้งแต่บรรทัดนี้ลงไป

ผมชื่อศิลป เป็น 1 ใน 2 คนที่ build prototype นี้ในงาน Thailand AI Extreme Hack 2026 (แข่ง 2 วัน) ผมไม่ได้เขียนโค้ดเป็น คุณจะเป็นคนเขียนให้ ผมจะเป็นคนตัดสินใจเรื่องหน้าตาและตรวจผลลัพธ์

**โปรเจกต์: "เล่าไว้"** — เว็บแอปที่หลานนั่งสัมภาษณ์ปู่ย่าตายาย AI ถอดเสียง ช่วยตั้งคำถามต่อ แล้วเรียบเรียงเป็นหนังสือชีวิต โดยทุกย่อหน้าต้องอ้างถ้อยคำต้นฉบับที่ตรวจสอบได้ และกดฟังเสียงจริงของท่านได้

อ่าน `docs/PROTOTYPE-PLAN.md` ก่อนเริ่ม

### ขอบเขตงานของผม (ห้ามแตะไฟล์นอกรายการนี้เด็ดขาด)
```
app/page.tsx          ← Landing page
app/book/**           ← หน้าหนังสือ A5 สำหรับพิมพ์
app/clip/**           ← หน้าเล่นเสียงบนมือถือ (ปลายทางของ QR)
components/**         ← component กลางทั้งหมด
app/globals.css       ← design token
tailwind.config.ts
public/fonts/**  public/images/**
```

**ห้ามแก้เด็ดขาด** (เพื่อนร่วมทีมชื่อนิคเป็นเจ้าของ กำลังเขียนพร้อมกันอยู่):
`lib/**`, `app/api/**`, `app/interview/**`, `app/review/**`, `supabase/**`, `package.json`, `.env.local`

ถ้างานผมจำเป็นต้องแก้ไฟล์ของนิค → **หยุด แล้วบอกผม** ผมจะไปคุยกับเขาเอง อย่าแก้เอง
ถ้าต้องลง library เพิ่ม → **หยุด แล้วบอกผม** อย่ารัน `npm install` เอง

### ข้อมูลที่ใช้ build
ยังไม่ต้องรอ API ของนิค **ใช้ mock ใน `data/demo/*.json` ได้เลย** มันมีรูปร่างเหมือนของจริง 100%
type ทั้งหมดอยู่ใน `lib/types.ts` — **อ่านได้ ห้ามแก้** (เป็นสัญญากลางที่ freeze แล้ว)

### ลำดับงาน ทำตามนี้เป๊ะ อย่าข้าม
**งานที่ 1 — design token + component 4 ตัว (1 ชม.)**
- ใน `app/globals.css` วาง CSS variable: สี, spacing, radius ทำครบทั้ง light/dark
- ฟอนต์: **Sarabun** (UI) + **Noto Serif Thai** (เนื้อหาหนังสือ) — self-host ใน `public/fonts` ห้ามใช้ Google Fonts CDN เพราะตอนพิมพ์ออฟไลน์จะหาย
- ตอนนี้ใน `components/` มี stub 4 ตัวที่นิคเขียนโครงไว้ ให้คุณเขียนไส้ในให้สวย **แต่ props ห้ามเปลี่ยนแม้แต่ตัวเดียว** เพราะหน้าของนิค import ไปใช้อยู่:
  - `<AudioPlayer src clipId startMs? endMs? compact? />` — waveform ด้วย wavesurfer.js, ต้อง seek ไปที่ startMs ได้
  - `<QRBox value size? />`
  - `<Highlight level="warn"|"ok">{children}</Highlight>` — warn = พื้นเหลือง หมายถึงประโยคที่ระบบจับได้ว่า AI เขียนเกินต้นฉบับ
  - `<StatPill label value />`
- ทำหน้า `/demo-components` ไว้ดูของทุกตัวในที่เดียว

**งานที่ 2 — `/clip/[token]` (45 นาที)**
หน้าเดียว จอมือถือ นี่คือหน้าที่กรรมการจะเห็นหลังสแกน QR ด้วยมือถือของเขาเอง ต้องสวยที่สุดต่อ 1 ตารางนิ้ว
มี: ชื่อผู้เล่า · คำถามที่ถูกถาม · ปุ่มเล่นใหญ่ + waveform · transcript อ่านตามได้ · ไม่มี nav ไม่มีอะไรให้กดผิด

**งานที่ 3 — `/book/[token]` (1.5 ชม.)**
หนังสือ A5 พร้อมพิมพ์: ปก · สารบัญ · เนื้อบท · หน้าปิด "คำฝากถึงหลาน" · QR ท้ายบท
- ใช้ `@media print` + `@page { size: A5; margin: 18mm }`
- **ห้ามใช้ react-pdf เด็ดขาด** มันไม่รองรับ text shaping ของไทย สระกับวรรณยุกต์จะซ้อนผิดตำแหน่ง เช่น "สื่อ" "ปู่" "ก๊อง" และตัดบรรทัดกลางคำ เราจะใช้ Ctrl+P → Save as PDF แทน ซึ่ง render ด้วย Chrome ทำไทยถูก 100%
- เนื้อหา `font-size` อย่างน้อย 15pt เพราะคนอ่านคือผู้สูงอายุ
- `page-break-inside: avoid` ที่ย่อหน้า อย่าให้ย่อหน้าขาดกลางหน้า
- ทดสอบด้วยการกด Ctrl+P จริงทุกครั้งที่แก้ แล้วดู preview

**งานที่ 4 — `/` Landing page (2.5 ชม.) งานใหญ่สุด**
กรรมการจะเห็นหน้านี้เป็นอย่างแรกตอน demo ต้องทำให้เขาเงียบใน 10 วินาทีแรก
1. **Hero** พื้นหลังมืด · waveform ของเสียงจริงคุณยายวิ่งอยู่ · ปุ่มเล่นใหญ่กดได้ทันที · ประโยค *"ปู่ย่าตายายของคุณ มีเรื่องเล่าอีกกี่เรื่อง ที่คุณยังไม่เคยฟัง"*
2. **ตัวเลข** นับขึ้นตอน scroll: ผู้สูงอายุไทย 16.8 ล้านคน · อยู่ลำพัง 1,348,397 คน · เสียชีวิต 559,684 คนต่อปี
3. **เปรียบเทียบ** อัดคลิปทิ้งไว้ในมือถือ (ไม่มีใครกลับมาฟัง หาไม่เจอ) ↔ เล่าไว้ (เป็นบท ค้นได้ มีเสียงจริง)
4. **"เราไม่ทำ deadbot"** — section จริยธรรมของตัวเอง: เราเก็บเสียงจริง ไม่สร้างเสียงปลอม AI เป็นผู้ช่วยฟัง ไม่ใช่ตัวแทนคนที่จากไป
5. **"ทุกย่อหน้าพิสูจน์ได้"** — โชว์ย่อหน้าตัวอย่างที่มีไฮไลต์เหลืองกับปุ่มฟังเสียง อธิบายว่าตรวจด้วยโค้ด ไม่ใช่ให้ AI ตรวจ AI
6. **ตัวอย่างหน้าหนังสือ** + QR ที่สแกนจากหน้าจอได้จริง
7. **CTA** → `/interview`
- ใช้ framer-motion แต่พอดี อย่าให้ช้า อย่าให้เมา
- ต้องสวยบนมือถือด้วย กรรมการอาจเปิดจากเครื่องตัวเอง

**งานที่ 5 — ขัดหน้าของนิค**
`/interview` กับ `/review` ให้แก้ **เฉพาะ className และ layout** ห้ามแตะ logic หรือ state ถ้าไม่แน่ใจว่าบรรทัดไหนคือ logic → ถามผมก่อน

### วิธีทำงานกับผม
- ทำทีละงาน เสร็จแล้วบอกให้ผมเปิดดูก่อนค่อยไปงานถัดไป อย่าทำ 3 งานรวดแล้วค่อยให้ดู
- หลังเสร็จแต่ละงาน: `git pull --rebase` แล้ว `git add` เฉพาะไฟล์ในขอบเขตผม แล้ว commit + push
- ถ้า `git pull` ขึ้น conflict → **หยุด บอกผมทันที** อย่าแก้เอง (ปกติไม่ควรเกิด เพราะเราแบ่งไฟล์กันแล้ว)
- อธิบายให้ผมฟังเป็นภาษาไทยเสมอ ผมอ่านโค้ดไม่ออก
- ถ้าผมสั่งอะไรที่จะพังโปรเจกต์หรือชนกับงานนิค ให้เตือนผมก่อน อย่าทำตามเฉยๆ

เริ่มที่ **งานที่ 1** ได้เลย อ่าน `lib/types.ts` กับ `data/demo/` ก่อนลงมือ
